# API de Infracciones Vehiculares

API REST desarrollada en Java para la gestión y consulta de infracciones vehiculares.

## Descripción

Este proyecto implementa un servicio web para administrar información relacionada con infracciones de tránsito. Forma parte de una práctica de desarrollo backend y diseño de APIs REST.

## Tecnologías

- Java
- API REST

## Funcionalidades

- Gestión de infracciones vehiculares
- Consulta de información mediante endpoints REST
- Organización del proyecto orientada al desarrollo backend

## Ejecución

1. Clona el repositorio.
2. Abre el proyecto en tu IDE de Java.
3. Configura las variables o servicios necesarios.
4. Ejecuta la aplicación.
